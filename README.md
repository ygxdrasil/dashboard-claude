# Life Dashboard

Personal dashboard. One user, desktop only. See `SPEC.md` for the full plan.

## Run it locally

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in the values (never commit `.env.local`).
3. `npm run dev` and open http://localhost:3000
